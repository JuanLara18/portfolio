# front

The React app behind the site, and the content it serves. For the project overview see the [root README](../README.md). For how it all fits together, see the [documentation](../docs/README.md).

## Develop

```bash
npm install
npm start          # http://localhost:3000
npm test           # unit tests
npm run build      # content pipeline plus production build into build/
```

`npm start` reads the generated indexes in `src/data/`, which are committed. Run `npm run build-blog-data` after adding or editing a post to refresh them without a full build.

## Layout

```
front/
├── public/
│   ├── blog/posts/<category>/<slug>.md   posts, fetched by the post page at runtime
│   ├── blog/headers/                     header images and ATTRIBUTIONS.md
│   ├── blog/figures/                     in-post figures
│   ├── blog/audio{,-es}/                 narration manifests
│   ├── 404.html, index.html              deep-link handling for GitHub Pages
│   ├── sitemap.xml, rss.xml              generated by prebuild
├── scripts/                              content pipeline, see scripts/README.md
└── src/
    ├── App.js                            routes, all pages lazy-loaded
    ├── pages/                            one component per route
    ├── components/
    │   ├── common/SEO.jsx                meta tags, canonical URLs, JSON-LD
    │   ├── features/blog/                Markdown renderer, post card, audio player
    │   ├── layout/                       navigation, footer, page transitions
    │   └── ui/                           visual building blocks
    ├── data/
    │   ├── blogData.json                 generated: post metadata
    │   ├── booksData.json                generated: books and papers index
    │   ├── series.js                     reading series, edited by hand
    │   └── brand.js                      site copy, mirrors docs/brand.md
    └── utils/
        ├── blogUtils.js                  post data access, on-demand bodies
        └── postLinks.js                  resolution of links between posts
```

## Conventions

- **Generated files are never edited by hand.** `blogData.json`, `booksData.json`, `sitemap.xml`, `rss.xml`, and `knowledge-base/posts.json` are rewritten by `prebuild`.
- **Lists of posts import `PostCard` directly** from `components/features/blog/PostCard`, not from the folder index. The index also exports the Markdown renderer, which would pull Mermaid and KaTeX into every listing page.
- **Copy comes from `src/data/brand.js`**, the code-side mirror of the brand book.
- **Links between posts are `/blog/<slug>`.** See [authoring](../docs/authoring.md#links-to-other-posts-enforced).

Commands, CI/CD, and troubleshooting are in [operations](../docs/operations.md).
